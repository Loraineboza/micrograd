# Micrograd

## Назначение проекта

Проект реализует небольшой движок автоматического дифференцирования на NumPy для обучения и исследования вычислительных графов.

В отличие от PyTorch, здесь используется минимальный API на основе класса `Tensor`, который отслеживает зависимости между узлами и выполняет обратное распространение градиентов вручную.

## Вычислительный граф и обратный проход

Каждый узел вычислительного графа хранит:

- `data` — числовое значение массива или скаляра;
- `grad` — накопленный градиент;
- `parents` — родительские узлы, от которых зависит текущая операция;
- `_backward` — функция вычисления градиентов для конкретной операции;
- `requires_grad` — признак участия тензора в вычислении градиентов.

После вычисления целевой функции вызывается `loss.backward()`.

Метод выполняет обход графа в топологическом порядке, а затем запускает обратные функции узлов в обратном порядке — от результата к входным данным.

Для вычисления градиентов используется правило цепочки. Если один узел участвует в нескольких ветвях вычислительного графа, вклады от этих ветвей суммируются.

## Поддерживаемые операции

Реализованы:

- поэлементное сложение и вычитание;
- поэлементное умножение и деление;
- возведение в степень;
- матричное умножение `@` для двумерных массивов;
- `sum()` и `mean()` с параметрами `axis` и `keepdims`;
- изменение формы массива через `reshape()`;
- транспонирование;
- операции `exp`, `log`, `sigmoid`, `tanh`, `relu`, `clip`;
- broadcasting при арифметических операциях;
- простые линейные слои через `Linear` и `MLP`.

## Накопление градиентов и broadcasting

Один и тот же узел вычислительного графа может использоваться в нескольких операциях. Поэтому градиенты от разных путей суммируются, а не перезаписываются.

Например:

```python
self.grad += ...
other.grad += ...
```

Это позволяет корректно учитывать вклад нескольких ветвей графа в итоговый градиент.

При broadcasting градиент приводится обратно к исходной форме тензора. Для этого выполняется суммирование по осям, добавленным при broadcasting.

Например, при сложении массива формы `(8, 2)` с вектором формы `(2,)` градиент вектора вычисляется суммированием по первой оси.

## Повторный вызов `backward()`

При повторном вызове `backward()` возникала проблема с градиентами промежуточных узлов вычислительного графа: значения, оставшиеся после предыдущего обратного прохода, могли повторно участвовать в следующем вычислении. Это приводило к некорректному накоплению градиентов.

Проблема исправлена в методе `backward()`:

1. Перед обратным проходом градиенты промежуточных узлов обнуляются.
2. Градиент корневого узла устанавливается в единицы.
3. Обратное распространение выполняется заново в обратном топологическом порядке.
4. Градиенты листовых узлов накапливаются через `+=`, сохраняя результаты предыдущих вызовов `backward()`.

Таким образом, промежуточные градиенты пересчитываются при каждом вызове, а градиенты листовых узлов накапливаются.

Для полного сброса градиентов используется метод `zero_grad()`.

## Известные ограничения

- `__matmul__` поддерживает только двумерные массивы. Неподдерживаемые формы вызывают `ValueError`.
- Реализация не является полной заменой PyTorch, JAX или TensorFlow.
- Поддерживается ограниченный набор операций и оптимизаций.
- Корректность вычислений при broadcasting зависит от правильного суммирования градиентов по соответствующим осям.

## Проверочный пример: X @ W + b

Следующий пример демонстрирует вычисление линейной модели и обратное распространение градиентов с использованием собственного autodiff:

```python
import numpy as np
from micrograd.autograd import Tensor

rng = np.random.default_rng(0)

X = rng.standard_normal((8, 3), dtype=np.float64)
W = rng.standard_normal((3, 2), dtype=np.float64)
b = np.array([0.5, -0.5], dtype=np.float64)
Y = rng.standard_normal((8, 2), dtype=np.float64)

X_t = Tensor(X, requires_grad=False, name="X")
W_t = Tensor(W, requires_grad=True, name="W")
b_t = Tensor(b, requires_grad=True, name="b")
Y_t = Tensor(Y, requires_grad=False, name="Y")

P = X_t @ W_t + b_t
L = ((P - Y_t) ** 2).mean()

L.backward()
```

В результате вычисляются:

- `P.shape == (8, 2)`;
- значение функции потерь `mean((P - Y) ** 2)`;
- `W_t.grad` — градиент функции потерь по весам;
- `b_t.grad` — градиент функции потерь по смещению.
