## Математическая основа

### 1. Вычислительный граф

Вычислительный граф представляет математическое выражение в виде последовательности операций и зависимостей между переменными.

Например:

`f(x) = x² + 2x + 1`

Граф отслеживает зависимости между исходными переменными, промежуточными результатами и итоговым значением функции. Это позволяет автоматически вычислять производные без ручного дифференцирования всего выражения.

### 2. Производная и градиент

Производная показывает, как изменяется значение функции при изменении входной переменной.

Например:

`f(x) = x²`

Производная:

`f'(x) = 2x`

При `x = 3`:

`f'(3) = 2 · 3 = 6`

### 3. Цепное правило

Цепное правило позволяет вычислять производную сложной функции через производные её отдельных частей.

Если:

- `y = g(x)`
- `z = f(y)`

то:

`dz/dx = (dz/dy) · (dy/dx)`

Рассмотрим пример:

`y = x²`

`z = y + 3`

Производные отдельных функций:

`dy/dx = 2x`

`dz/dy = 1`

Следовательно:

`dz/dx = 1 · 2x = 2x`

Именно этот принцип лежит в основе обратного распространения градиентов в вычислительном графе.

### 4. Обратное распространение ошибки (Backpropagation)

При обучении нейронной сети необходимо определить, как каждый параметр влияет на функцию потерь.

Для параметра `w` градиент записывается как:

`dL/dw`

Он показывает, как изменяется функция потерь `L` при изменении параметра `w`.

Если функция потерь зависит от промежуточного значения `y`, которое зависит от параметра `w`, применяется цепное правило:

`dL/dw = (dL/dy) · (dy/dw)`

Градиенты распространяются от выходных вычислений к предыдущим узлам графа. Если параметр влияет на результат через несколько ветвей, соответствующие вклады в его градиент суммируются.

### 5. Градиентный спуск

Градиенты используются для обновления параметров модели с целью уменьшения функции потерь.

Правило обновления параметра:

`w_new = w_old - learning_rate · dL/dw`

где:

- `w_old` — текущее значение параметра;
- `w_new` — новое значение параметра;
- `learning_rate` — скорость обучения;
- `dL/dw` — градиент функции потерь по параметру.

Пример:

`w_old = 2`

`dL/dw = 4`

`learning_rate = 0.1`

После обновления:

`w_new = 2 - 0.1 · 4 = 1.6`

Градиент определяет направление изменения параметра, а скорость обучения — размер шага.
