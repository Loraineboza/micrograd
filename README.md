# Micrograd — движок автоматического дифференцирования

Реализация собственного движка автоматического дифференцирования на Python с нуля. Проект посвящён изучению внутренних механизмов вычислительных графов, распространения градиентов и обратного распространения ошибки (Backpropagation).

## Возможности

- **Вычислительный граф (Computational Graph)** — построение графа зависимостей между скалярными значениями и математическими операциями.
- **Автоматическое дифференцирование (Automatic Differentiation)** — вычисление производных сложных выражений с помощью цепного правила.
- **Обратное распространение ошибки (Backpropagation)** — вычисление градиентов путём обратного обхода вычислительного графа.
- **Поддержка математических операций** — выполнение арифметических операций с отслеживанием их влияния на итоговый результат.
- **Накопление градиентов** — корректная обработка узлов, используемых в нескольких ветвях вычислительного графа.
- **Нейросетевые компоненты** — базовые строительные блоки для создания нейронов, слоёв и многослойных перцептронов (MLP).
- **Обучение нейронных сетей** — возможность использовать вычисленные градиенты для обновления параметров модели с помощью градиентного спуска.

## Основные компоненты

### `Value`

Базовый класс для представления скалярных значений. Хранит числовое значение, градиент и зависимости от предыдущих узлов вычислительного графа.

### Вычислительный граф

Каждая операция создаёт зависимости между входными и выходными значениями. Граф сохраняет структуру вычислений, необходимую для последующего вычисления производных.

### `backward()`

Запускает обратное распространение градиентов. Вычисления выполняются в обратном порядке относительно исходных операций, а локальные производные объединяются согласно цепному правилу.

### Нейросетевые модули

Позволяют организовывать параметры и вычисления в нейроны и слои, формируя основу для построения и обучения многослойных перцептронов.

## Математическая основа

Автоматическое дифференцирование использует цепное правило:

\[
\frac{\partial L}{\partial x}
=
\frac{\partial L}{\partial y}
\frac{\partial y}{\partial x}
\]

Для функции потерь \(L\) градиенты последовательно распространяются от выходных вычислений к параметрам модели. Полученные производные позволяют определить, как изменение каждого параметра влияет на значение функции потерь.

## Технологии

- **Python** — реализация вычислительного движка.
- **NumPy** — численные вычисления и вспомогательные операции, если используются в соответствующих компонентах проекта.

## Цель проекта

Разобраться во внутренних механизмах автоматического дифференцирования и обучении нейронных сетей на низком уровне, без опоры на готовые движки градиентов вроде `torch.autograd`.

Проект служит практической основой для понимания того, как вычислительные графы, цепное правило и обратное распространение градиентов работают внутри современных фреймворков глубокого обучения.
