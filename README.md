# Micrograd

Небольшой движок автоматического дифференцирования на NumPy. Проект реализует вычислительный граф, обратное распространение градиентов и базовые операции над массивами.

## Возможности

- Tensor с хранением data, grad, parents и функций обратного прохода;
- поэлементные арифметические операции и broadcasting;
- матричное умножение для двумерных массивов;
- sum и mean с axis, keepdims, отрицательными осями и кортежами осей;
- exp, log, sigmoid, tanh, relu и clip;
- простые Linear и MLP модули;
- численная проверка градиентов центральными конечными разностями.

## Семантика backward и накопления градиентов

Каждый вызов backward() выполняет новый обратный проход по графу:

1. Градиенты промежуточных узлов (узлов, у которых есть parents) обнуляются перед проходом. Они являются рабочими буферами текущего вычисления.
2. Градиент корневого узла устанавливается в единицы.
3. Градиенты листовых узлов накапливаются между вызовами backward(). Поэтому для x = Tensor([2.0]); loss = (x*x).sum() последовательные вызовы дают x.grad = 4, 8, 12. Вызов backward() непосредственно на листовом тензоре также накапливает единичный seed.
4. zero_grad() сбрасывает накопленные градиенты листьев и всех достижимых узлов графа.

Ветви графа, сходящиеся к одному узлу, обрабатываются один раз в топологическом порядке: обход использует множество посещённых узлов, а локальные производные складывают вклады через +=. Это сохраняет сумму вкладов всех путей без повторного использования промежуточного градиента от предыдущего вызова.

## Суммирование

sum(axis=None, keepdims=False) и mean(axis=None, keepdims=False) поддерживают:
- axis=None;
- одну ось, включая отрицательную;
- кортеж или список осей;
- оба значения keepdims.

axis должен соответствовать правилам NumPy. Повторяющиеся оси и оси вне диапазона отклоняются NumPy/проверкой осей. __matmul__ поддерживает только двумерные массивы.

## Численная проверка градиентов для X @ W + b

Скрипт examples/gradcheck.py проверяет аналитические градиенты W и b для функции:

~~~python
L = mean((X @ W + b - Y) ** 2)
~~~

Проверка использует float64, центральную конечную разность с шагом 1e-6 и критерий:

~~~text
abs(g_analytic - g_numeric) <= 1e-6 + 1e-4 * max(abs(g_numeric))
~~~

Фактический запуск в GitHub Actions (Python 3.11.18, NumPy 2.4.6, float64) дал: шаг конечной разности 1e-6; допуск 9.693318610612e-05; максимальная абсолютная ошибка W = 2.218909500584e-10; максимальная абсолютная ошибка b = 5.379396927907e-11. Проверка завершилась сообщением Gradient check PASSED. Запуск: https://github.com/Loraineboza/micrograd/actions/runs/43743622569. Для повторного получения отчёта выполните python examples/gradcheck.py.

## История изменений в рамках технической проверки

До уточняющего задания существовали движок Tensor, операции, простые нейросетевые модули, тесты и пример линейной регрессии. В рамках доработки проверки добавлены регрессионные тесты повторного обратного прохода и sum(keepdims=True), исправлена обработка промежуточных градиентов, добавлена явная обработка формы градиента после редукции, исправлена точка входа test.py и добавлены метаданные устанавливаемого Python-пакета.

Конкретный дефект повторного backward() был выявлен при проверке: промежуточные градиенты оставались от прошлого прохода и повторно участвовали в распространении. Дефект воспроизведён отдельными регрессионными тестами. Для sum добавлены проверки осей 0 и 1, отрицательной оси, кортежа осей и обоих режимов keepdims.

Исходная реализация проекта принадлежит автору репозитория. При подготовке исправлений и тестовой документации для этого этапа использовался ChatGPT как инструмент разработки и ревью; поэтому эти доработки не заявляются как выполненные без помощи ИИ. Для формул и API использовались документация NumPy и pytest.

## Ограничения

Это учебная минимальная реализация autodiff, а не полная замена PyTorch/JAX. В частности, matmul ограничен двумерными массивами; нет автоматической оптимизации графа, CUDA, sparse-тензоров и полного набора операций современных DL-фреймворков.

## Описание проекта для технической проверки

**Назначение.** Проект — учебная реализация автоматического дифференцирования на NumPy. Он показывает, как из операций над массивами строится вычислительный граф и как градиенты распространяются в обратном порядке. Это отдельная работа от PyTorch-эксперимента и Faster R-CNN-детектора в репозитории [mp4_detector](https://github.com/Loraineboza/mp4_detector/tree/review/second-stage-2026-11).

**Состояние.** Реализованы базовые операции Tensor, обратное распространение, простые нейросетевые слои, пример линейной регрессии, численная проверка градиентов и автоматические тесты. Проект не является полноценной заменой промышленного autodiff-фреймворка.

**История и дата начала.** Точная дата начала первоначальной разработки в README и доступных материалах проекта не зафиксирована; её не следует восстанавливать предположением. Для точной даты используйте историю Git (`git log --reverse`).

**Личный вклад.** В репозитории представлены собственные модули `micrograd/autograd.py`, `micrograd/losses.py`, `micrograd/nn.py`, примеры и тесты. В рамках второго этапа технической проверки были дополнены регрессионные тесты, обработка повторного `backward()`, проверки редукций и упаковка проекта. Эти изменения готовились с использованием ChatGPT для разработки и ревью; они не заявляются как выполненные полностью самостоятельно без ИИ.

**Входы и выходы.** Tensor принимает числовые скалярные значения или NumPy-массивы. Арифметические операции и матричное умножение создают новые узлы графа; `backward()` вычисляет градиенты относительно листовых узлов. `__matmul__` ограничен двумерными массивами, а набор операций намеренно меньше, чем в PyTorch/JAX.

**Проверка ошибки.** При проверке повторного `backward()` обнаружилось, что промежуточные градиенты могли переноситься между обратными проходами. Поведение зафиксировано регрессионными тестами; рабочие градиенты промежуточных узлов сбрасываются перед новым проходом, а накопление градиентов листьев сохраняется. Численная проверка центральными конечными разностями используется как независимая проверка аналитических градиентов.

**Архитектуры и оптимизация.** В проекте есть простые Linear/MLP-компоненты и пример линейной регрессии. Систематическое сравнение архитектур или бенчмарк производительности не проводились и в качестве результата не заявляются.
